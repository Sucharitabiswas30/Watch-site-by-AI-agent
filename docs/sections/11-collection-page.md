# 11 — All watches collection

Dedicated `/collections` catalogue containing 60 demo watches. An editorial collection image introduces the page. Visitors can filter for men's or women's watches using image-by-image wearer classifications, combine that choice with five collection types, search, sort by name or price, progressively reveal products, and add items to a local demo bag. The closing brand statement uses a darkened parallax watch image with a mobile-safe static fallback, followed by the same full footer as the homepage.
